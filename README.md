# Ôn tập Tiếng Anh 4 (Global Success)

Web ôn tập cho học sinh lớp 4: từ vựng và mẫu câu 20 Unit, 17 trò chơi ôn tập theo từng Unit, bài tập bổ trợ tự chấm (tab Bài tập), đề kiểm tra Nghe – Đọc – Viết – Nói, máy tự chấm điểm.

## Chạy trên GitHub Pages
1. Tạo repository mới, tải toàn bộ file trong thư mục này lên (giữ nguyên thư mục `pages/`).
2. Vào **Settings → Pages**, chọn nhánh `main`, thư mục `/ (root)`, bấm Save.
3. Mở đường dẫn `https://<tên-tài-khoản>.github.io/<tên-repo>/`.

Chạy trên máy: mở thẳng `index.html` bằng Chrome hoặc Edge.

## Cấu trúc
- `index.html`: toàn bộ ứng dụng (HTML, CSS, JavaScript).
- `pages/`: ảnh các trang sách (`uN-k.jpg`, N = Unit 1–20, k = 1–6).
- `README.md`, `.nojekyll`.

Giọng đọc dùng giọng tiếng Anh Mỹ có sẵn trong trình duyệt. Điểm cao nhất lưu trong trình duyệt của từng máy.


## Luyện nói (cô Lan)
Tab "Luyện nói": nhắc lại, shadowing, hỏi đáp, nhập vai, phát âm, nói theo tranh, nói liền mạch. Chấm giọng bằng micro chỉ hoạt động trên Chrome/Edge khi trang chạy qua HTTPS (GitHub Pages); nơi khác dùng gõ chữ hoặc tự chấm.

## Thuyết trình
Tab "Thuyết trình": bạn học sinh nữ (giọng Anh Mỹ của trình duyệt) thuyết trình từng Unit, chừa tên/tuổi/lớp/trường cho học sinh; có chế độ tự thuyết trình và thu âm.
